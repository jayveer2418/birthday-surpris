BIRTHDAY SURPRISE — OCTOBER 4

Files:
- index.html  = website
- style.css   = design
- script.js   = countdown + interactions
- photos/     = photo assets extracted from the supplied reference video

IMPORTANT:
1. Open index.html in Chrome.
2. Replace photos/photo1.jpg ... photo6.jpg with your own photos if you want.
3. To add music, put an MP3 named music.mp3 beside index.html.
4. The birthday date is set to October 4, 2026 in script.js.
   If you want another year, change BIRTHDAY_DATE.
